Create file `.env.example` with all required environment variables:
- OLLAMA_BASE_URL=http://localhost:11434
- WHISPER_MODEL=base
- TTS_VOICE=deep_male
- MARKET_API_KEY=your_key_here
- WSL2_ENABLED=true

Create file `requirements.txt` (Python) or `package.json` (Node.js) with all dependencies.

Create file `README.md` with setup instructions:
1. How to install Ollama models (qwen3-coder, deepseek-coder-v2, qwen2.5-coder-7b)
2. How to install Whisper and TTS engines
3. How to enable WSL2
4. How to start the backend and frontend
